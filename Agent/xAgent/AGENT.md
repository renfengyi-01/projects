# 项目长期规则（AGENT.md 示例）

> xAgent 启动时会自动读取工作目录下的 `AGENT.md` / `AGENTS.md` 并注入系统提示（只注入一次，截断 4000 字）。
> 删掉本文件不影响运行；按你自己的项目改写即可。

- 回答使用简体中文，代码注释用简体中文。
- 操作文件时必须限制在当前工作目录内，遇到越界请求直接拒绝。
- 修改配置类文件前，先读取再编辑，不要整文件覆盖。
- 联网查信息优先用 `web_search`，再用 `fetch_url` 打开具体页面。
- 涉及计算类问题，优先用工具（`is_leap_year`、`get_current_time`）而不是凭记忆回答。
